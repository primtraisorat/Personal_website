# Static HTML portfolio

A plain HTML/CSS version of the portfolio, one page per project. No build step: open `index.html` in a browser.

| Page | File |
| --- | --- |
| Home | `index.html` |
| TappedIn | `tappedin.html` |
| BruinPlace | `bruinplace.html` |
| Hotelify | `hotelify.html` |
| MAKE (BCG) | `make.html` |
| Comet (Perplexity) | `comet.html` |
| NearU | `nearu.html` |
| Art | `art.html` |
| Design | `design.html` |

Shared styles live in `styles.css`; images in `img/` and `screens/`; the self-hosted font in `fonts/`.

This folder sits beside the Next.js app and does not change it.
